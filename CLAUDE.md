## Stack
- Python 3 Flask server (`app.py`, `core/`, `platforms/`, `reach_bridge/`) run offline-first on Termux; pip deps listed in `requirements.txt`.
- Android client in `android-apk/`: Java WebView bridge (`com.devsaged.nexussocial`), compileSdk/targetSdk 34, built by `.github/workflows/build-apk.yml`. No WebToApp.
- Zip uploads are unpacked by `.github/workflows/unpack-zip.yml`; `docs/code-index.md` is generated by `repomap.yml`.
- Offline first: every network call in try/catch with a graceful fallback. Arabic RTL UI.

## Architecture
